## Breakpoints

### Phpstorm
In Phpstorm, there is already a config setting file that set the necessary settings to have the breakpoints. <br>
If you don't want the setting file, you can follow the next instructions : 
<br>
<br>
Go to "Settings" then "PHP->Servers" and set a new server :
- name : "symfony"
- host : "http://localhost"
- port : 80
- Use path mapping : Yes
- File/Directory : < yourPathToLoLSauce >/symfony
- Absolute path on server : /app <br>
<br>
**Save** <br>
